# ハロ：ブロック風の外観研究

**[English](README.en.md) | 日本語**

[日本語の比較ページ](https://ktanino10.github.io/haro-brick-kit/) · [360°ビュー](https://ktanino10.github.io/haro-brick-kit/viewer360.html) · [English site](https://ktanino10.github.io/haro-brick-kit/en/)

同じ大きさのブロックを使い、ベーシック版とディテール版（青い目）の
40・60・80・100 cm級を比較する、非公式の個人制作研究です。
CG・実寸・部品数・360°表示は、同じ8案の配置JSONに基づきます。

**外観確認用・印刷用の完成設計ではありません。**
下面の空洞・嵌合、強度、支持、組立順、印刷は未検証で、製造設計は保留中です。
STL／3MF／組立手順や、重量・印刷時間の見積もりは提供していません。

## 見られるもの

- 同じ表示サイズ／同じ縮尺での8案比較と、100 cm級の正面CG。
- マウスのドラッグ／ホイール、1本指／ピンチ操作による本当の3D回転とズーム。
- 正面・背面・上面・下面、リセット、自動回転の開始／停止。
- 日本語・英語の操作・読み込み・エラー・診断・注意事項。

全案共通で **8 mmピッチ、本体高9.6 mm、スタッド径4.8 mm・高さ1.8 mm**。
2×2／2×4だけを使い、模型全体を拡大してブロック寸法を変える方式ではありません。
60 cm級の外径目標は608 mm、100 cm級は992 mmです。
個数は外殻・内部リブを含み、台座・ヒンジ・予備・試験片を除きます。

## オフラインで開く

サイトの「単独で使える360° HTMLを保存」からダウンロードできます。
または、このリポジトリーをZIPで保存・展開し、`docs/index.html` を開いてください。
英語版は `docs/en/index.html`、各フォルダーの `viewer360.html` が360°ビューです。
ビューアーはライブラリと8案を内蔵し、CDN・ログイン・ローカルサーバー・利用者のインストールは不要です。
HTML単体でも3Dは動きますが、比較ページ・言語リンクには同梱ページが必要です。
WebGL 2対応ブラウザーが必要で、操作速度は端末に依存します。

## ソースと再生成

`data/` が配置・寸法・パレット・集計の基準、`src/` が描画と翻訳、
`scripts/` がビルドと検査、`docs/` がGitHub Pagesの公開対象です。
3種類の共通形状をGPUインスタンスで共有し、選択した1案だけを描画します。
上方向はZ、正面は−Y、mmから表示単位への換算は模型ルートの固定0.001のみです。
スタッドは元の外形CGと同じ12角形で、下面の嵌合CADを表すものではありません。

開発者向け（閲覧だけなら不要）：

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run test:unit
```

`npm run test:browser` はPlaywright Coreを使います。
`HARO_BROWSER_PATH` にインストール済みChromium系ブラウザーの実行ファイルを指定してください。
結果の保存先は `HARO_TEST_OUTPUT` で指定でき、既定の `test-output/` は公開しません。
`HARO_LIVE_URL` を指定すると同じ検査を公開サイトに対して行えます。
ブラウザーの通常プロファイルやGPU設定は変更しません。

ページ全体の未捕捉例外は3D本体の失敗と区別します。
ホスト側の通知権限プローブなどの失敗で模型を消すことはなく、
本体の起動・配置・描画・操作の失敗は明示します。診断はページ内だけで、送信しません。
ヘッドレスタブの非表示検査は可視状態イベントの模擬であり、実スマートフォンの性能保証ではありません。
